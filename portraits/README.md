# 立绘文件夹

把做好的立绘放在这个文件夹里，**文件名与角色姓名完全一致**，刷新页面即自动显示，无需任何导入操作。

## 预置角色命名对照

| 角色 | 文件名 |
| --- | --- |
| 朱志鑫 | `朱志鑫.png` |
| 左航 | `左航.png` |
| 苏新皓 | `苏新皓.png` |
| 张极 | `张极.png` |
| 张泽禹 | `张泽禹.png` |

## 说明

- 预置路径均为 `.png`。想改用 `.jpg` / `.webp`：在「角色 → 编辑 → 立绘图片 URL」中把路径改成对应文件名即可（如 `portraits/张极.jpg`）。
- 建议竖版构图（立绘位比例约 2:3）；透明底 PNG 效果最佳——镂空处会透出角色主题色。
- 文件缺失或加载失败时，舞台区保持显示不透明占位符，不影响正常使用。
- 新建角色：在角色表单的立绘 URL 填 `portraits/新角色名.png`，文件同样按姓名命名即可。
- 某些静态托管对中文文件名支持不佳时，可改用拼音命名（如 `portraits/zhangji.png`），并同步修改角色表单里的立绘 URL。
