## ADDED Requirements

### Requirement: 角色管理面板展示已存在角色列表
系统 SHALL 在用户打开角色管理面板时，展示当前世界观下全部已存在角色的列表。每个列表条目 MUST 包含角色头像、姓名、设定摘要、出场状态开关，以及编辑与删除入口。列表形态与世界观管理面板一致（条目列表 + 底部「新建」「关闭」按钮）。当前世界观没有任何角色时，列表 MUST 为空且保留「新建角色」入口。

#### Scenario: 打开面板即见列表
- **WHEN** 用户点击右上角「角色」按钮打开角色管理面板
- **THEN** 面板中展示当前世界观所有已存在角色的列表条目（含预置角色），而非仅显示「新建」「关闭」按钮

#### Scenario: 空世界观
- **WHEN** 用户在没有任何角色的世界观下打开角色管理面板
- **THEN** 列表为空，「新建角色」入口可用

### Requirement: 从列表直接编辑角色
系统 SHALL 允许用户从角色列表点入任一已存在角色进行修改：点击条目的编辑入口（「编辑」按钮或角色信息区）MUST 打开编辑表单，且表单各字段（姓名、立绘图片、主题色、设定）预填该角色的当前值。保存后，角色列表、场景条、舞台区立绘与叙事视角选项 MUST 同步反映更新，后续对话生成 MUST 使用更新后的角色设定。

#### Scenario: 点入编辑预填信息
- **WHEN** 用户点击列表中某角色的编辑入口
- **THEN** 打开编辑表单，姓名、立绘、主题色、设定各字段显示该角色当前保存的值

#### Scenario: 保存修改同步生效
- **WHEN** 用户在编辑表单中修改某角色的设定并保存
- **THEN** 角色列表、场景条、舞台区与视角选项立即显示更新后的信息，后续对话生成使用更新后的角色设定

#### Scenario: 列表内切换出场状态
- **WHEN** 用户在角色列表中切换某角色的出场开关
- **THEN** 该角色出场状态更新，场景条与舞台区同步刷新，角色管理面板保持打开
