## Purpose

提供提示词驱动的角色互动对话：基于当前世界观与出场角色档案，由 LLM 以 SSE 流式生成可选叙事视角的互动内容，支持多角色加入场景与受约束 HTML 富渲染。

## ADDED Requirements

### Requirement: LLM API 配置
系统 SHALL 提供设置界面，允许用户配置 OpenAI 兼容 Chat Completions API 的 Base URL、API Key 与模型名称。配置 MUST 仅保存在浏览器本地，仅发往用户配置的端点。生成参数（如温度、max_tokens）SHALL 使用固定的内置默认值，不向用户暴露。

#### Scenario: 保存配置
- **WHEN** 用户填写 Base URL、API Key、模型名并保存
- **THEN** 配置存入本地并用于后续对话生成

#### Scenario: 未配置时提示
- **WHEN** 用户未配置 API 信息就发送提示词
- **THEN** 系统提示先去设置页完成配置，不发起请求

### Requirement: SSE 流式生成
系统 SHALL 以 stream 模式调用 Chat Completions API，并将 AI 回复随数据到达逐段渲染到对话气泡中。系统 SHALL 提供"停止生成"操作，停止后 MUST 保留已生成的部分内容。请求失败或中断时系统 MUST 显示错误信息且不破坏已有对话记录。

#### Scenario: 流式渲染
- **WHEN** 用户发送提示词且 API 开始返回流式数据
- **THEN** 对话气泡随内容到达逐步增长显示，而非等全部生成完才出现

#### Scenario: 停止生成
- **WHEN** 用户在生成过程中点击"停止"
- **THEN** 请求被中止，已生成的部分内容保留为一条完整消息

#### Scenario: 生成失败
- **WHEN** LLM 请求失败或流中断
- **THEN** 界面显示可理解的错误提示，已有对话记录保持不变

### Requirement: 提示词驱动对话生成
系统 SHALL 根据用户输入的提示词（剧情指令或角色台词），结合当前世界观设定、出场角色档案与对话历史调用 LLM 生成角色互动内容，并以聊天气泡形式追加到对话记录中。

#### Scenario: 成功生成
- **WHEN** 用户在当前世界观下输入提示词并发送
- **THEN** 系统以该世界观的设定与角色档案为上下文生成互动内容并显示

### Requirement: 受约束 HTML 富渲染
系统 SHALL 允许 AI 回复中包含 HTML 片段（用于手机消息界面、回忆卡片、系统提示框等剧情元素），前端 MUST 经白名单消毒后渲染：仅允许安全标签与内联样式，MUST 移除 script、事件处理器与外部资源加载。纯文本内容按普通文本渲染。系统 SHALL NOT 使用 Markdown 渲染。

#### Scenario: 富元素渲染
- **WHEN** AI 回复中包含白名单内的 HTML 片段（如一个带内联样式的卡片）
- **THEN** 该片段以富样式渲染显示在气泡中

#### Scenario: 危险内容消毒
- **WHEN** AI 回复中包含 script 标签或事件处理器等危险内容
- **THEN** 渲染前这些内容被移除，页面行为不受影响

### Requirement: 可选叙事视角
系统 SHALL 允许用户在生成时选择叙事视角：出场角色中任一角色的视角，或上帝（全知）视角。生成内容 MUST 符合所选视角的叙事口吻（角色视角用第一人称内心呈现，上帝视角用第三人称叙述）。

#### Scenario: 角色视角生成
- **WHEN** 用户选择角色 A 视角并发送提示词
- **THEN** 生成内容以角色 A 的第一人称视角展开

#### Scenario: 上帝视角生成
- **WHEN** 用户选择上帝视角并发送提示词
- **THEN** 生成内容以第三人称叙述所有出场角色的互动

### Requirement: 多角色加入场景
系统 SHALL 允许用户将当前世界观下的任意角色标记为"出场"或"离场"。对话生成 MUST 仅包含出场角色的互动；新加入的角色 MUST 能被 LLM 感知并纳入后续生成。

#### Scenario: 拉入新角色
- **WHEN** 用户将世界观内的第三个角色标记为出场并发送提示词
- **THEN** 生成内容包含该新角色的参与互动

#### Scenario: 角色离场
- **WHEN** 用户将某出场角色标记为离场
- **THEN** 后续生成不再让该角色发言或行动，历史记录保留

### Requirement: 对话记录管理
系统 SHALL 按世界观分别保存对话记录。系统 SHALL 允许用户删除单条消息、重新生成最近一条 AI 回复，以及清空当前世界观的对话记录。

#### Scenario: 重新生成
- **WHEN** 用户对最近一条 AI 回复点击"重新生成"
- **THEN** 系统基于相同上下文重新生成并替换该条回复

#### Scenario: 清空对话
- **WHEN** 用户清空当前世界观对话并确认
- **THEN** 仅当前世界观的对话记录被删除，其他世界观不受影响
