## Why

当前界面是淡紫色调的通用聊天 UI，视觉平淡、缺乏「小剧场」的戏剧感；角色只有圆形小头像，立绘没有展示位置，原型阶段也看不出未来美术资源的占位布局；交互反馈（点击、聚焦、视角切换）几乎没有动画，操作手感单薄。需要一次整体的美术风格升级，让原型在视觉和交互上更接近目标体验。

## What Changes

- 全局换用**高饱和度卡通 + 像素点缀**的美术风格：鲜亮配色、粗描边、夸张圆润的造型，搭配像素风图标 / 边框 / 纹理点缀（星露谷式 UI 质感），替换现有淡紫扁平风格。
- 新增**顶部舞台区**：位于场景条与对话区之间，以视觉小说方式并排展示出场角色的立绘位置；原型阶段立绘用**不透明占位符**（非半透明、非轮廓线）呈现，明确标示未来立绘的占位与尺寸；舞台随角色出场 / 离场联动更新。
- 新增**视角联动背景**：切换叙事视角（上帝视角 / 各角色视角）时，舞台与对话区背景切换为对应的主题色 / 图案，并带过渡动画。
- 新增**交互动画**：按钮与可点元素的点击特效（如涟漪 / 弹跳）、输入框与控件的聚焦特效、弹层开合与视角切换的过渡动画。
- 不改数据层、LLM 调用与消息渲染逻辑；localStorage 数据结构保持兼容，无 BREAKING 变更。

## Capabilities

### New Capabilities

- `visual-style`: 全局美术主题——高饱和卡通 + 像素点缀的配色、描边、造型与装饰规范，覆盖主界面与弹层。
- `character-stage`: 顶部舞台区——出场角色立绘的不透明占位展示、随出场 / 离场联动、以及随叙事视角切换的背景变化。
- `ui-animation`: 交互动画——点击特效、聚焦特效与界面过渡动画的行为规范。

### Modified Capabilities

（无——主 specs 目录为空，既有行为规格仍在中途 change `cp-roleplay-chat` 中，本变更不改动其需求。）

## Impact

- **代码**：仅影响单文件 `index.html` 的内联 CSS 与渲染 / 事件绑定部分的 JS；数据层（localStorage 结构）、SSE 调用、HTML 消毒逻辑不受影响。
- **依赖**：无新增第三方依赖，保持零构建单文件形态。
- **文档**：`README.md` 的玩法说明可补充舞台区与视角背景的描述（顺带更新，非必须）。
- **兼容性**：既有世界观 / 角色 / 对话数据不受影响；角色 `avatar` 字段继续作为立绘图片来源（留空时显示占位符）。
